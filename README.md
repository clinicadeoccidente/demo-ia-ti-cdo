# demo-ia-ti-cdo
## Modo Seminario (prototipo)
Abrir `seminario.html` para acceder al menú cinematográfico y a los paneles de demostración existentes. `index.html` y la carpeta `paneles/` se conservan sin modificaciones. La votación incluida es local (no multiusuario); para una encuesta real en el evento integrar un proveedor de encuestas o backend. Publicar y validar en un entorno de prueba antes de cambiar la página principal.
